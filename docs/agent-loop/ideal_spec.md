# Спецификация проекта

Продуктовые контракты, инварианты хранения и переходы состояний определяет [ADR](../ADR.md). Контракты зависимостей определяет [EXTERNAL_SERVICES.md](../EXTERNAL_SERVICES.md), условия приёмки описаны в [TEST_PLAN.md](../TEST_PLAN.md).

- Rental, Source и Payment являются отдельными Go-модулями и собираются из собственных директорий. Корневой go.work предназначен для локальной работы со всеми модулями.
- У каждого сервиса есть собственный Dockerfile. Source и Payment имеют по одной точке входа cmd/main.go. Rental имеет три точки входа cmd/api, cmd/worker и cmd/maintenance, каждая вызывает свой Run. Сервисы связываются по HTTP.
- SQL-миграции принадлежат сервису, который владеет БД. PostgreSQL 17 и goose используются для Rental. Source и Payment используют память процесса.
- Внутренние пакеты организованы по предметным областям. В каждом предметном пакете маршруты и обработчики находятся в http.go, их DTO в dto.go, а доменные модели в model.go. Пакеты объявляют RegisterRoutes, оркестратор подключает их к общему роутеру. Инварианты проверяются в конструкторах моделей, условия переходов — методами модели по актуальным данным. Прикладные операции координируют переходы и транзакции, а слой хранения выполняет SQL. Старт заказа и завершение поездки атомарно записывают соответствующие фоновые задачи.
- Репозиторий каждого домена закрыт внутри пакета. Операции хранения доступны другим пакетам через сервис домена. Операции в общей транзакции принимают транзакцию вызывающего сервиса.
- Сервис, которому нужна транзакция, владеет её прикладным сценарием. Отдельный пакет сценария вводится, если зависимые домены нельзя связать внутри сервиса-владельца. Общий механизм PostgreSQL и настройки процесса находятся в platform внутри модуля Rental.
- Публичные offer_id и order_id представлены UUID в строковом виде. Локальные значения config при холодном старте равны 1.25, 0.8, 365 дням, пустой карте зон и TTL тарифов 10 минут.
- Стенд использует Docker Compose. Для HTTP выбран Echo v5.4.7. Для наблюдаемости используются Prometheus, Grafana и структурированные JSON-логи slog.
