# Проверки

- Из корня выполнить `make check`. Цель запускает тесты с детектором гонок и vet у каждого модуля с `GOWORK=off`, затем собирает пять бинарников в `build/`. Проверки PostgreSQL запускаются отдельной командой.
- Для интеграционных тестов Rental установить `RENTAL_TEST_DATABASE_URL` на выделенный PostgreSQL 17 с правом создавать тестовую схему и выполнить `make test-integration`. Тесты должны пройти на конкурентный старт из одного оффера и разных офферов для одного самоката, закрытие просроченного START и повторы завершения после переноса в историю, откат заказа и оффера при сбое вставки задачи START, повтор старта при сбое Source, успешный результат последней попытки с действующим lease, завершение при исчерпанных попытках и приоритет дедлайна.
- Проверить `docker compose config --quiet`, затем собирать и запускать только нужные сервисы Compose. Для работающих сервисов проверить HTTP `/healthz`, `/metrics`, у Rental дополнительно `/readyz` и состояние миграции. После запуска проверить логи затронутых сервисов.
- Проверка загрузки Go workspace запускает из корня `go test ./services/rental/... ./services/source/... ./services/payment/...`.

- Пока HTTP-каркас реализован как TODO, тесты сборки роутеров трёх сервисов проверяют все 12 маршрутов и JSON-ответ 501. Образ Rental содержит исполняемые API, worker и maintenance. На стенде API по-прежнему запускается после мигратора.
