# Точки входа сервисов

- По запросу пользователя перенесли композицию Rental, Source и Payment в internal/app. Единственную точку входа каждого модуля подняли в cmd/main.go. Обновили импорты и пути сборки в Dockerfile
- GOWORK=off go test -race и go vet прошли во всех модулях. Интеграционные тесты Rental повторены без кэша на PostgreSQL 17. Общий запуск через go.work также прошёл
- Все образы собраны из ./cmd. В тестовом Compose проверены /healthz и /metrics трёх сервисов, /readyz Rental и успешный запуск мигратора. Версия схемы 1
- Независимая проверка приняла перенос. Подтверждены отдельные точки входа, локальные импорты и передача аргумента migrate. Новых рисков по переносу нет
