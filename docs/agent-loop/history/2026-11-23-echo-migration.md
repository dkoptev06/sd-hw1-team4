# Переход на Echo

- Закрепили Echo v5.4.7 во всех трёх Go-модулях. Доменные пакеты объявляют RegisterRoutes, оркестраторы собирают роутер. DTO и 12 путей ADR сохранены
- Используем echo.StartConfig для HTTP-процессов с прежними таймаутами. Prometheus подключён через echo.WrapHandler, стартовые логи остались JSON, команда migrate сохранена
- Независимая проверка приняла перенос. Вне маршрутов ADR применяются стандартные ответы Echo. На стенде OPTIONS /offers вернул 204, ответы маршрутизатора 404 и 405 имеют JSON-тело
- GOWORK=off go test -count=1 -race, go vet и go build прошли у трёх модулей. Интеграционные тесты Rental использовали PostgreSQL 17. Запуск тестов через go.work также прошёл
- В выделенном Compose проверили 12 ответов 501, health, метрики, readiness Rental и успешный запуск мигратора. Временный процесс Source завершился с кодом 0 после SIGTERM. Операции с Git отсутствуют
