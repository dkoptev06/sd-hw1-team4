- В корне добавлен `Makefile` с целями `check`, `test`, `test-integration`, `vet`, `build` и `up`. Go-команды работают по модулям с `GOWORK=off`. Для тестов PostgreSQL требуется явный DSN, обычные тесты запускаются без него. `build` сохраняет пять бинарников в `build/`.
- Новый `README.md` описывает запуск команд, стенд и проектные документы. Исходный README перенесён в `docs/assignment-readme.MD`, поскольку на локальной файловой системе имена отличаются только регистром. SHA-256 исходного текста совпал до и после переноса.
- `make check` и интеграционные тесты на PostgreSQL 17 прошли. Проверены сообщение и ненулевой код при пустом DSN, наличие пяти исполняемых файлов и совместимость с GNU Make 3.81.
- `make up` проверен на Compose-проекте `rental-core-verify-7f23`. Мигратор завершился с кодом 0, Rental, Source и Payment прошли проверки `/healthz` и `/metrics`, Rental также прошёл `/readyz`. Проверены логи запуска.
