# HTTP-контракты и процессы Rental

- Добавили 12 маршрутов Rental, Source и Payment по ADR. HTTP DTO отделены от предметных пакетов. Обработчики содержат TODO и возвращают JSON с кодом 501
- Собрали API, worker и maintenance как отдельные точки входа с собственными Run в модуле Rental. API и команда migrate используют прежний интерфейс Compose. Циклы worker и maintenance ожидают реализации в профильных срезах
- Зафиксировали построение снимка оффера, конфигурации и попытки START через конструкторы. Условия переходов проверяются в моделях. Прикладные сервисы сохраняют порядок блокировок и атомарность записи заказа и задачи
- GOWORK=off go test -count=1 -race, go vet и go build прошли во всех модулях. Интеграционные тесты Rental использовали PostgreSQL 17. Образы собраны, на тестовом Compose проверены все 12 маршрутов, мигратор и три бинарника Rental
- Независимая проверка приняла маршруты, DTO, точки входа и сохранение транзакционных гарантий. Операции с Git по запросу пользователя отсутствуют
