# Общая инфраструктура транзакций Rental

- Вынесли открытие пула, DBTX и TxRunner в internal/platform/postgres по согласованному подходу checker-advanced. Операции, которым нужна открытая транзакция, принимают postgres.Tx. Прикладные сценарии выполняются локально в order и offer
- Загрузку DATABASE_URL перенесли в internal/platform/config. Политика хранения и настройки предметной области остаются внутри Rental
- GOWORK=off go test -count=1 -race, go vet и go build прошли. На PostgreSQL 17 проверили откат оффера и заказа при отказе записи START и успешный повтор
- Собрали и запустили только Rental. Проверили мигратор, health, readiness и metrics. Независимый валидатор принял разделение и сохранение порядка блокировок
- Отдельный пакет сценария понадобится, если зависимости нельзя будет связать внутри сервиса-владельца. Новых рисков по переносу нет
