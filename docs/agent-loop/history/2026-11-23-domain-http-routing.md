# HTTP-маршруты предметных пакетов

- Перенесли объявления маршрутов и обработчики в http.go пакетов офферов, заказов, самокатов, тарифных зон, профилей, конфигурации и платежей. DTO каждого пакета находятся в соседнем dto.go
- Оркестраторы подключают RegisterRoutes к общему роутеру. Тесты обращаются к этой же сборке. Rental и Source используют общий внутри своего модуля помощник для временного ответа 501
- Все 12 маршрутов и JSON-контракты сохранены. GOWORK=off go test -count=1 -race, go vet и go build прошли у трёх модулей. Интеграционные тесты Rental использовали PostgreSQL 17
- Собраны и проверены три HTTP-процесса на выделенном Compose. Все 12 маршрутов вернули 501 NOT_IMPLEMENTED. Независимый валидатор принял перенос. Операции с Git отсутствуют
